# Bloodborne for Apple Silicon 0.8.1

This update fixes a repeatable crash while playing at native 1080p and adds MetalFX as an optional
upscaler on macOS.

## Crashes and shader cache

- A live dynamic-shadows setting could turn shadows back on in a secondary render context that
  has no shadow target. Its worker could then crash. The setting still changes live in normal
  scenes; the game now keeps shadows off only where that context requires it. The copied-save
  crash was reproduced on Metal and MoltenVK before the fix. Both renderers passed copied-save
  tests afterwards, including a five-minute Metal run with left turns.
- Metal's render recorder keeps shader and pipeline objects alive until queued draws finish.
- A tessellation shader could assign the same output location twice, causing MoltenVK to reject
  its pipeline. That error was also reported as a “damaged” shader cache. The shader is corrected,
  and a rejected pipeline is no longer saved for the next launch. The shader cache rebuilds once
  after this update to replace older generated shaders; the next launch should reuse it.

## MetalFX (Apple)

MetalFX is a new choice under **Graphics → Upscaling** in the launcher and the in-game menu. It
works with either renderer on supported Macs and uses the same Quality, Balanced and other
presets. The big FPS overlay shows MetalFX and both resolutions. FSR 3.1 remains the default. On
an M3 Pro at 1080p Balanced in one copied-save scene,
FSR's median frame time was 21.3 ms and MetalFX's was 23.9 ms; both had about 28–29 ms p90. Choose
the picture you prefer. MetalFX is still experimental; please report visual errors or stalls with
the game log.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`. No game files are included: supply your own
Bloodborne dump with update 1.09. The app includes its runtime, bash, Python and libraries.

Known issues from
[0.8.0](https://github.com/bloodborne-native/bloodborne-mac/blob/main/docs/releases/v0.8.0.md#known-issues)
remain, including black characters above about 3.5 million render pixels. Brief FPS dips are
still under investigation.
